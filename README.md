# App

A Vite + React app for the storefront experience in this repository.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app locally:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Project notes

- This repo is a standard Vite + React app.
- Local authentication, consent, and session handling remain in the app itself.
- If you want to run the app in a browser, use the Vite dev server output URL.
